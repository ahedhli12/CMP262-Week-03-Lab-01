# CMP 262 – Data Science Programming

## Week 3 – Lab 1: Python Lists and Tuples

Welcome to **CMP 262 – Data Science Programming**.

This lab introduces two important Python data structures: **lists** and **tuples**. You will practice storing multiple values, accessing elements, modifying lists, looping through collections, and understanding the difference between mutable and immutable data structures while working in **Jupyter Notebook inside Visual Studio Code**.

## Lab Goal

By completing this lab, you will practice:

- Creating Python lists
- Accessing list elements using indexes
- Modifying list elements
- Adding and removing values from lists
- Using common list functions and methods
- Looping through lists
- Creating and accessing tuples
- Understanding the difference between lists and tuples
- Using lists and tuples with simple data
